# 🔍 Recruiters & Hiring Managers – Review My Portfolio Locally

Thank you for visiting my profile!

You can download and run my portfolio source code locally to explore its structure, design, and implementation.

### Option 1: Clone the repository

Open your terminal, PowerShell, or Command Prompt and run:

```bash
git clone https://github.com/sharmadevanshi22/Devanshi_Portfolio-.git
```

Navigate to the project folder:

```bash
cd Devanshi_Portfolio-
```

Open the project in Visual Studio Code:

```bash
code .
```

### Option 2: Download the ZIP

1. Visit [My Portfolio Repository](https://github.com/sharmadevanshi22/Devanshi_Portfolio-).
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded folder.
5. Open the folder in Visual Studio Code.

### Run the portfolio locally in Chrome

From the project directory, run:

```bash
python -m http.server 8000
```

Open Chrome and visit:

```text
http://localhost:8000
```

You can now explore the portfolio running on your local system.
