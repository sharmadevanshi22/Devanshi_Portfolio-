# Devanshi — Cloud & DevOps Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## 1. Personalise before publishing

Open `index.html` and replace:
- Confirm your email and LinkedIn details are correct.
- Add your GitHub username and replace the generic GitHub link.
- The project repository placeholders (`href="#"`) with actual public GitHub repository URLs.
- The resume link points to the included `assets/Devanshi_Resume.pdf`.

Review every technology tag and remove anything you have not used. Keep “learning” or “concepts” labels where appropriate. Add project screenshots, architecture diagrams, outcomes and README links only when they reflect work you actually completed.

## 2. Preview locally

You can double-click `index.html` to open it in a browser. For a local development server, open this folder in VS Code and use the Live Server extension, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## 3. Publish free with GitHub Pages

1. Create a GitHub repository named `YOUR-GITHUB.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and your `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub finishes publishing, visit `https://YOUR-GITHUB.github.io`.

## 4. Before sharing with recruiters

- Check the site on mobile and desktop.
- Test the resume download, email, LinkedIn, GitHub and project links.
- Make sure project descriptions are accurate and do not disclose employer confidential information.
- Add a credential verification link if you want recruiters to validate your AWS certification.
- Use a professional email address and a current PDF resume.
